# Link to FAIR resources

Foundation-level module linking to one fetched external resource: **FAIR resources (link)** at https://mygeohub.org/cybertraining/fair — the MyGeohub "What is FAIR?" page of the Cyber Training for FAIR Science site (navigation includes Courses, FACT Fellowship, 2020/2021/2022 FACT Fellows, 2021 FAIR Workshop, Team).

The page explains the 2016 'FAIR Guiding Principles for scientific data management and stewardship' published in Scientific Data: guidelines to improve findability, accessibility, interoperability, and reuse of digital assets, emphasizing machine-actionability. FAIR supports data reuse, knowledge sharing/collaboration, quicker discovery, and a simplified research cycle; it involves researchers, publishers, and repositories, with principles for data, metadata, and infrastructure. Objectives cover FAIR-compliant data repositories (metadata, landing pages, citation support, data curation) and FAIR-compliant Earth and space science publishers (data citations resolving to repository landing pages, no data in supplements).

**Findable:** persistent identifiers (PID types/schemes such as DOI; granularity of assignment), rich metadata (Dublin Core concepts, community metadata schemas, geolocation and temporal coverage, author/contact elements, ORCID, Researcher-ID, Scopus-ID), indexing in searchable resources (Crossref DOIs, sample IGSNs, CRediT author contributions), and metadata export via OAI-PMH, Linked Data Platform, ResourceSync, landing-page meta tags, plus re3data record accuracy.

**Accessible:** retrieval by identifier over standardized, open, free, universally implementable protocols (examples HTTP, FTP, SMTP, telephone; counter-examples Skype, Microsoft Exchange Server protocol); authentication/authorization where necessary (HMAC authentication, HTTPS, FTPS; the 'A' does not mean open — protected/private data can be FAIR); metadata persisting even when data disappear (principle A2, related to F4); machine-readable metadata embedded in landing pages via HTML tags, JSON-LD, XML.

**Interoperable:** formal, shared knowledge-representation languages and controlled vocabularies/ontologies/thesauri with good data models (examples RDF, Dublin Core Schema, OWL, DAML+OIL, JSON-LD); FAIR vocabularies (FAIR Data Point specification); qualified references between (meta)data (example http://www.uniprot.org/uniprot/C8V1L6.rdf).

**Reusable:** plurality of accurate, relevant attributes (scope, limitations, generation date, lab conditions, parameter settings, software name/version, raw vs processed, variable definitions, versioning); clear data usage licenses (MIT, Creative Commons, DTL FAIRifier); provenance (origin, workflow, citation; Wikimedia Commons CC-BY-SA example); domain-relevant community standards (MIAME, MIAPE; http://schema.datacite.org/, ISO 53798 geographic information, cfconventions.org climate and forecast).

Closing resources: article on the Enabling FAIR Data Project, Nov 16-17 2017 Stakeholder Meeting outcome, DataONE webinar recording, and the Enabling FAIR Data project site.
