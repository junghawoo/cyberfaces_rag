# Building Blocks of FAIR

This foundational unit introduces FAIR (Findable, Accessible, Interoperable, Reusable) data principles—guiding principles for scientific data management, stewardship, and reuse.

## What Is FAIR?

FAIR stands for four core principles:

**Findability**: Data must be easily discoverable by both humans and computational systems through searchable metadata.

**Accessibility**: Once found, users must access data through standardized, open protocols; includes authentication/authorization where necessary; metadata remain accessible even when data becomes unavailable.

**Interoperability**: Data must integrate with other datasets and interoperate with applications/workflows; uses formal knowledge representation languages, shared controlled vocabularies, and qualified references to other metadata.

**Reusability**: Ultimate FAIR goal—optimize data reuse through rich descriptive metadata, clear usage licenses, detailed provenance information, and adherence to domain-relevant community standards.

## FAIR vs. Open Data

FAIR and open data are distinct concepts:

- **Open Data**: Data freely downloadable from internet; broad accessibility focus
- **FAIR Data**: Emphasizes data utility for stakeholders; includes DOIs (Digital Object Identifiers), machine-actionability, persistent identifiers, standardized metadata

**Philosophy**: "As open as possible, as closed as necessary." Not all FAIR data is open; sensitive data (medical information, threatened species locations) may remain restricted while maintaining FAIR principles through public metadata and controlled access pathways.

## FAIR Principles Details

### Findability (F1-F4)
- F1: Globally unique, eternally persistent identifiers (GUIDs)
- F2: Rich metadata describing data
- F3: Registered/indexed in searchable resources
- F4: Metadata specify data identifier

### Accessibility (A1-A2)
- A1: Retrievable via identifier using standardized protocols
- A1.1: Protocol open, free, universally implementable
- A1.2: Authentication/authorization procedures where needed
- A2: Metadata accessible when data unavailable

### Interoperability (I1-I3)
- I1: Formal, accessible, shared language for knowledge representation
- I2: Vocabularies following FAIR principles
- I3: Qualified references to other metadata

### Reusability (R1-R1.3)
- R1: Richly described with accurate, relevant attributes
- R1.1: Clear, accessible usage license
- R1.2: Detailed provenance (collection conditions, selection rationale)
- R1.3: Domain-relevant community standards compliance

## FAIR in Climate and Geoscience

Climate/geoscience researchers employ FAIR principles to make data available globally through repositories and journals, promoting scientific transparency and preventing misinformation through evidence-based analysis. Publishing to certified trusted data repositories (CoreTrustSeal certification) ensures long-term accessibility and preservation.

## Implementation Framework

### Machine-Actionability
Emphasis on computational systems finding, accessing, interoperating, reusing data with minimal human intervention—critical as data volume, complexity, creation speed increase.

### Three-Point FAIRification Framework
Practical guidance for implementing FAIR:
1. Assign persistent identifiers (DOI)
2. Provide rich, standardized metadata
3. Register in searchable repositories

### Key Infrastructure Elements

**Metadata Requirements**:
- Creator information; creation location/date
- Data content description; citations/credits
- Keywords; field of science codes
- Related paper DOIs; researcher ORCID identifiers
- Grant codes; provenance details

## Summarized attachments
- **FAIR Principles** (https://www.go-fair.org/fair-principles/, link): GO FAIR website presenting foundational FAIR Guiding Principles for scientific data management and stewardship with detailed explanations of Findability, Accessibility, Interoperability, and Reusability principles including specific sub-principles F1-F4, A1-A2, I1-I3, R1-R1.3.
- **FAIR data principles** (https://www.youtube.com/watch?v=F13nkArkp_A, video): YouTube video introducing FAIR data principles with discussion of findability through DOIs and repositories, accessibility with appropriate mechanisms, interoperability through standard protocols and vocabularies, and reusability with clear licenses and provenance information.
- **The FAIR Data Principles** (https://force11.org/info/the-fair-data-principles/, link): FORCE11 website documenting the FAIR Guiding Principles from 2016 Scientific Data publication with detailed specifications for making data Findable, Accessible, Interoperable, and Reusable including working detailed document and archived resources.
- **What scientists need to know about FAIR data** (https://www.nature.com/nature-index/news-blog/what-scientists-need-to-know-about-fair-data, link): Nature Index article discussing distinction between FAIR and open data, importance of metadata, DOIs and persistent identifiers, FAIR principles application, repository selection (Zenodo, Figshare, OSF), and benefits for researcher careers and data management.

## Stakeholder Responsibilities

**Researchers**:
- Maintain ORCID identifier
- Use institutional/discipline repositories
- Assign DOIs to data
- Consider long-term data accessibility
- Use standardized formats/metadata

**Editors**:
- Promote trusted repository use
- Standardize journal data policies
- Encourage consistent publication practices

**Research Support Staff**:
- Facilitate researcher data management
- Provide metadata/standards guidance
- Support repository workflows
- Deliver FAIR skills development

**Institutions**:
- Maintain institutional repositories
- Develop FAIR data self-assessment tools
- Train research support staff
- Support repository certification
