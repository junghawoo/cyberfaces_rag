# Accessing biodiversity data from NEON

Tutorial on downloading, accessing, and processing biodiversity and environmental data from National Environmental Observation Network (NEON). Data sources: cloud servers; output formats: CSV, standard database formats.

Learning objectives: Access USGS NWIS Surface Data Portal using Python; pre-process USGS streamflow data.

Lab assignment includes basic Python tutorial (Using Python as a Calculator):

Arithmetic operations: Basic operators (addition, multiplication, subtraction, division); integer vs floating-point number types. Examples: 2+2=4, 4*30=120, (50-5*6)/4=5.0 (float due to division).

Variables: Define using equals sign (=); naming rules: start with letter or underscore, alphanumeric + underscores allowed; reserved words prohibited (and, as, assert, break, class, continue, def, del, elif, else, except, exec, finally, for, from, global, if, import, in, is, lambda, not, or, pass, print, raise, return, try, while, with, yield).

Examples: width=20, length=30, area=600, volume=6000; error handling for undefined variables.

Jupyter Notebook execution: Shift-Enter to evaluate cells.

Resources: Python Tutorial (http://docs.python.org/3/tutorial/introduction.html), IPython tutorial (ipython.readthedocs.io) for sophisticated interactive shell.

Lab assignment notebook: https://github.com/nujwoo/python101/01cal.ipynb (GitHub link for Python basics).

Additional materials: VTT subtitle files (German: subtitles-de.vtt, English: subtitles-en.vtt), OCR image content showing Wheat field 429 management zones, productivity maps, nitrogen recommendations (Max ROI/Balanced/Max yield strategies), field parameters (potential 1.5-1.7 T/ac), management recommendations, video file (ElephantsDream.mp4).

Estimated effort: Foundation level; covers basic Python syntax and data access fundamentals.
