# Data, visualization, & regression

## Summary

This unit covers environmental data analysis in Python, spanning FAIR (Findable, Accessible, Interoperable, Reusable) data principles, data acquisition from public repositories, statistical visualization, and regression modeling. The course ENVR 890-001: Python for Environmental Research (Fall 2020) is taught by Andrew Hamilton with contributions from Matthew Huber and Ashley Dicks (Purdue University).

**FAIR Data & Environmental Data Sources:** The module emphasizes that FAIR data must be findable by humans and computers, accessible without barriers, interoperable in usable formats with clear metadata, and reusable by various users. Major public environmental data repositories include USGS National Water Information System (stream flow, water quality, water use; e.g., Bolin Creek data at https://waterdata.usgs.gov/nwis/uv?site_no=0209734440), Natural Resources Conservation Service (NRCS) snow depth and water supply forecasts, NOAA National Centers for Environmental Information (historical weather, severe weather databases), EPA Air Data (current and historical air quality with automated plotting), EPA Dataset Giveaway (climate change, Superfund sites, environmental justice), CDC National Center for Environmental Health (asthma, lead poisoning, nutrition), OECD Data (country-scale environment, energy, healthcare, development), USGS The National Map (National Hydrography Dataset, Digital Elevation Maps, place names, transportation), Multi-Resolution Land Characteristics Consortium (MRLC) land use/land cover datasets, and NCAR Research Data Archive (gridded oceanic and atmospheric datasets/reanalyses). Data upload methods into Python include pd.read_csv()/read_excel() from downloaded CSV/XLSX files, copying online tables to Excel, using special Python APIs (EPA Envirofacts Data Service API, USGS API via kapadia package, requiring accounts and different implementations per provider), and querying online tables directly via URLs using pandas.

**Visualization Fundamentals:** Data visualization uses matplotlib pyplot module (typically imported as plt) with seaborn (sns) for enhanced functionality. Key matplotlib settings include rcParams.update({'font.size': 18}) for adjusting default font sizes. Basic plotting involves passing data arrays to plot functions; for example, plotting parabolas with plt.plot(X, Y1) and plt.plot(X, Y2) together, then customizing with plt.figure(figsize=(10, 6)) for size control. Figure customization includes plt.xlabel()/ylabel() for axis labels, plt.legend(loc='upper center') for legend placement, and line styling with color (e.g., 'mediumturquoise', 'mediumslateblue'), linestyle ('--' for dashed), linewidth (numeric), alpha (0.0-1.0 transparency), and markers ('d' for diamond). Chapel Hill weather data example (NOAA GHCND station USC00311677) demonstrates loading CSV files with pd.read_csv(), renaming columns, converting date strings to datetime format via pd.to_datetime(), indexing by date, extracting temporal features (df.index.year, .month, .day), and filtering subsets (e.g., df.loc[df['year'] >= 1970]).

**Regression Analysis:** Linear regression is implemented via statsmodels.formula.api as sm with equation syntax in quotes (e.g., 'nox ~ year') without explicit constant terms. Ordinary Least Squares (OLS) minimizes squared errors to find coefficients β0 (intercept) and β1 (slope) in the form y_i = β0 + β1*x_i + ε_i. Example uses EPA Acid Rain emissions database (NC/SC coal plants, 1997-2020, quarterly SO2/NOx/CO2/heat input data) analyzing NOx vs. year. Regression results from lm_fit.summary() provide R-squared (0.601 in example), adjusted R-squared, F-statistic (283.2), p-values, coefficients with 95% confidence intervals, and regression diagnostics (Omnibus, Durbin-Watson, Jarque-Bera tests, condition numbers). Normality assumptions are checked via histogram histograms, QQ-plots (statsmodels.graphics.gofplots.qqplot), and Shapiro-Wilk test (scipy.stats.shapiro). Box-Cox transformation (scipy.stats.boxcox) improves normality by applying power transformation with lambda parameter; for example, lambda=0.06979 for NOx data yields better Shapiro-Wilk p-value (0.0785 vs. 0.048). Predicted values from regression coefficients allow visualization of regression lines overlaid on scatterplots using sns.scatterplot() and plt.plot().

**Advanced Regression Techniques:** Multiple regression adds categorical variables (e.g., state[T.SC] for binary state indicator) and interaction terms (year:state[T.SC] for differential slopes). Example regresses nox_bc (Box-Cox transformed NOx) on year and state with results showing state effect (coefficient -1.4557) and interaction not significant (p=0.301). Categorical variables like quarter require conversion to string type (df['quarter_cat'] = [str(q) for q in df['quarter']]) for dummy encoding. One-way ANOVA tests differences in means (scipy.stats.f_oneway) between groups; example shows significant difference between NC and SC (F=37.51, p=5.2e-9). Homoskedasticity (constant variance) is checked via residual plots (sns.scatterplot of year vs. residuals). Data smoothing techniques include simple line segments through yearly means (df.groupby('year').mean()) and LOWESS smoothing (statsmodels.nonparametric.smoothers_lowess.lowess) with adjustable frac parameter (e.g., frac=0.2 uses 20% of data for each smoothed value).

**Homework & Learning Objectives:** HW6 assignments require finding environmental science/engineering/public health datasets from listed repositories or personal research, reading and cleaning data (handling NaNs and anomalies), performing groupings (annual, monthly), creating two+ visualizations (line plots, scatter plots, histograms, box plots), and performing two+ regressions (not necessarily statistically valid, but demonstrating regression competency). Deliverables are well-documented Jupyter notebooks due October 23. The in-class exercise asks students to test statistically significant CO2 emission reductions in North Carolina with appropriate transformations and statistical checks. Supporting references include: Wilkinson et al. (2020) FAIR guiding principles in Scientific Data; Stall (2018) AGU FAIR data presentation; Merwade et al. MyGeoHub FAIR principles; Hutton et al. (2016) computational hydrology reproducibility (Water Resources Research); Huston et al. (2019) open data for public health (Canada Communicable Disease Report); Rosenberg et al. (2020) reproducible research practices (Journal of Water Resources Planning and Management); McElreath (2020) YouTube lecture on scientific reproducibility. External links point to GitHub repositories with code (hamilton-2020 paper repository with Zenodo snapshots/DOIs), HydroShare, Nature Scientific Data repositories, and GitHub+Zenodo integration examples.
