# Justice in Data: FAIR Data Principles

This Foundation-level "Justice in Data" bootcamp module teaches the FAIR data principles (Findable, Accessible, Interoperable, Reusable). Resources include the slide deck `FAIR_Principles_FINAL.pdf`, a FAIR Data Principles Pre-Survey (QuestionPro/utaedu link), and a recording (YouTube yE451byTkLM), presented by Dr. Forbes with instructors including Junaid and Dr. Park.

Lecture objectives: define the FAIR data principles and describe the importance of incorporating them into research. Background: over $2.1 trillion is spent globally each year on R&D producing reusable datasets; only 28% of researchers are familiar with FAIR per the 2021 State of Open Data report by Digital Science. Theme: "With big data, comes big responsibility." FAIR enables computational systems to find, access, interoperate, and reuse data with minimal human intervention.

Key definitions covered: Repository (free online collection of scholarly documents/data; examples GitHub and Zenodo, with Zenodo interface shown); Machine-readable data (contrasted with scans of text; two groups — marked-up human-readable data such as HTML, and machine-processing formats such as CSV); Persistent Identifiers (PID/PI); Permalinks; Digital Object Identifiers (DOIs, example citation Mitchell, T. (1997) Sahel Precipitation Index dataset via JISAO, https://doi.org/10.6069/H5MW2F2Q); ROR (Research Organization Registry, example University of Texas at Arlington ROR ID https://ror.org/019kgqr73); ORCID (Open Researcher and Contributor ID, https://orcid.org/, example iD 0000-0001-8888-635X and Eric Schultz's ORCID with 127 works); Data vs. Metadata ("data about data").

FINDABLE principles (F1–F4): globally unique persistent identifiers; rich metadata; metadata explicitly include the data's identifier; (meta)data registered/indexed in a searchable resource. Example: student project on urbanization vs. extreme rainfall using Zenodo, indexed in OpenAIRE. Quiz question on qualities of identifiers (answer: B, C — unambiguously identify, operate for foreseeable future).

ACCESSIBLE principles (A1, A1.1, A1.2, A2): retrievable by identifier via standardized communication protocol; protocol open, free, universally implementable; supports authentication/authorization where needed; metadata accessible even when data no longer available. Sensitivity/security classes (public, confidential, highly confidential, restricted; levels 1–5). Motto: "As Open as Possible, As Closed as Necessary." Zenodo examples of closed/restricted access (monsoon rainfall data). Quiz on value of a landing page (answer: A — evidence research was conducted).

INTEROPERABLE principles (I1, I2, I3): formal, accessible, shared, broadly applicable knowledge-representation language; controlled vocabularies following FAIR; qualified references to other (meta)data (e.g., "is new version of," "is supplement to," "relates to"). Avoid proprietary software/licensed formats; prefer open formats (PDF, CSV, JPEG); standardize dates, time periods, geographic coordinates. Zenodo versioning example (150 versions). Quiz (answer: B, C, E).

REUSABLE principles (R1, R1.1, R1.2, R1.3): richly described with accurate attributes; clear accessible data usage license; detailed provenance (how/why/who); domain-relevant community standards. Example: temperature dataset from GOES satellite in a GitHub repository with MIT license and suggested citation. Quiz (answer: A, B, C, D).

Guidance for ensuring FAIR support: datasets open with a DOI, in open formats, discoverable via open search (e.g., Google); metadata with disciplinary terminology, machine-readable standards (ORCIDs), citation format, terms of use. Preparation tips: describe data collection methods and file structures, reference articles with contributors' ORCIDs, zip files, choose a well-known repository providing a DOI, provide license attribution. Benefits of FAIR: new discoveries, new collaborations, reduced duplication, verification of results, maximum research impact, increased visibility/citations, improved reproducibility, new partnerships, and enabling new research questions.
