# Repositories

Data repositories for research and FAIR science practices.

Repository definition: Collection of numeric/geospatial datasets for secondary research use. Purpose: safely store data for easy access, further research, analysis, reporting. Public repositories enable sharing between users. Quality control ensures completeness, consistency, documentation standards.

FAIR science enablement: Large public repositories increase data findability and accessibility. Quality control develops standards and ensures completeness/accuracy/consistency, enabling data reuse for further research.

Commonly used repositories:

PURR (Purdue University Research Repository, https://purr.purdue.edu/): Purdue's institutional repository providing online workspace for research and collaboration for students/staff.

GitHub (https://github.com/): Repository hosting service using Git version control; easy repository creation; variety of data management tools.

MyGeoHub (https://mygeohub.org/): Platform hosting course materials; hosts weather and Earth-based science datasets; provides tools for research and data management; online course workspaces.

Data.gov (https://www.data.gov/): US Government repository; open data covering Agriculture, Ocean data, Public Safety, and diverse topics.

Data.world (https://data.world/): Business-oriented repository; wide dataset collection; built-in R and Python code editing/writing kits; easy team collaboration.

Academic Torrents (http://academictorrents.com/): Scientific research data repository (similar to PURR); two-part structure: dataset search, data sharing/distribution; requires login access.

Common characteristic: All repositories follow FAIR science practices (Findable, Accessible, Interoperable, Reusable).

Data repository definition (Informatica): Enterprise data storage entity where data is partitioned for analytical or reporting purposes. Often used interchangeably with data warehouse/data mart; general term for purpose-built data segmentation. Not a product, but can use commercial (Oracle) or open-source (Hadoop) systems. Benefits: ease of reporting/analysis through isolation from other data.
