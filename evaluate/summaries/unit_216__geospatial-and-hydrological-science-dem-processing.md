# Geospatial & Hydrological Science: DEM Processing and Topographic Wetness Index (TWI)

Expert-level hands-on module on preprocessing Digital Elevation Model (DEM) raster data and generating a Topographic Wetness Index (TWI), prepared by Jibin Joseph and Venkatesh Merwade, Lyles School of Civil Engineering, Purdue University (joseph57@purdue.edu, vmerwade@purdue.edu), under the "FAIR Science in Water Resources" program.

**Resources.** Several versioned PDF instruction handouts: "PDF-Instructions_DEM Processing and TWI" (`Instructions_DP6_DEM_Processing_TWI_v05.pdf`), "PDF-Instructions_DEM Processing" (`Instructions_DP6_DEM_Processing_v02.pdf`, included twice), and "Instructions_DP6_DEM_Processing_v04" (`Instructions_DP6_DEM_Processing_v04.pdf`, included twice), plus the fetched Jupyter notebook "JN-DEM Processing and TWI" from GitHub: I-GUIDE/hydroewd `DEM_Process/Coursepage_DP6_DEM_Processing_v2d.ipynb`. Referenced notebooks include "JN-DEM Processing," "JN-DEM Access," and the "Launch Coursepage_DP6_DEM_Processing" link at https://github.com/I-GUIDE/hydroewd.

**Platforms and setup.** The tutorial runs on the CyberFaCES platform (www.cyberfaces.org; register/login via CILogon with institutional credentials, ORCID, or Google Account) using the preinstalled "ct-fair" conda kernel in the Interactive Jupyter Notebook Hub; the v02 variant also targets the I-GUIDE platform with the "Python [iguide-ewd]" kernel. Access paths go through Learn > "Take Course" / "Explore Modules," via the courses "I-GUIDE Forum 2024 Hands-on Tutorial: CyberTraining on Geospatial Data Processing using Python" and "WaterSciCon24 Hands-On Workshop: Web-based Modules on Geospatial Data Processing Using Python." Required Python packages when run elsewhere: rasterio (plot/merge/reproject), geopandas (shapefiles), pyproj (coordinate systems), shapely (clipping), and pywbt (TWI creation); the notebook also imports pynhd (NLDI), matplotlib, numpy, math, os, tempfile, and pathlib.

**Workflow steps.** (1) Define variables (USGS site number, resolution) and plot unmerged DEM tiles downloaded from the USGS National Elevation Dataset / National Map Viewer into `~/scratch/DEM_Access/data_<site_id>/raw_<site_id>/` (or `~/modules/hydroewd/DEM_Access/...` on I-GUIDE), overlaying the watershed shapefile; resolutions are 1, 1/3, or 1/9 arc-second, with a tile-overlap computation using shapely Polygon and geopandas overlay. (2) Merge/mosaic the raster tiles with `rasterio.merge`, creating intermediate and results folders and writing a `merge_dem_raster_func` that copies source metadata and skips merging when one tile covers the watershed. (3) Reproject shapefile and raster from geographic (EPSG:4326 / WGS84) to a projected coordinate system: compute the watershed centroid, estimate the UTM zone (EPSG:32616, WGS 84 / UTM zone 16N for the demo watershed; conterminous-US zone lookup 08–22 or `estimate_utm_crs`), reproject the shapefile with `to_crs`, and reproject the raster with `calculate_default_transform`, `reproject`, and `Resampling` from rasterio.warp. (4) Clip the reprojected raster to the watershed (with a buffer, in meters) using `rasterio.mask.mask` and shapely `mapping`, reducing storage and processing time. (5) Generate TWI from the clipped DEM using Whitebox Tools (WBT) via pywbt: BreachDepressions (fill pits), D8Pointer flow direction (D8 algorithm), DownslopeFlowpathLength, D8FlowAccumulation with specific contributing area output, Slope (degrees), and WetnessIndex, then plot all six rasters (clipped DEM, depression-filled DEM, D8 flow direction, slope, flow accumulation/SCA, TWI) in a comparison grid with viridis/plasma colormaps.

**Study sites.** Primary example: USGS site 03363000, Cedar Creek watershed. Optional practice sites: Yellowstone River at Yellowstone Lk Outlet YNP, WY (06186500), Kissimmee River at S-65E near Okeechobee, FL (02273000), and Susquehanna River at Bainbridge, New York (01502632). Output files follow patterns like `merged_<res>_<site>.tif`, `reprojected_<res>_<site>.tif`, `clipped_<res>_<site>.tif`, `proj_shp_<site>.shp`, and `twi_<res>_<site>.tif` under `~/scratch/DEM_Process`.

**References cited.** Hawker, Bates, Neal & Rougier (2018) on DEM simulation for flood modeling, Frontiers in Earth Science; Saksena & Merwade (2015) on DEM resolution and flood inundation mapping, Journal of Hydrology; Chegini, Li & Leung (2021) HyRiver: Hydroclimate Data Retriever, Journal of Open Source Software; Python urllib.request documentation; Gillies (2019) Rasterio documentation (MapBox); pywbt documentation (pywbt.readthedocs.io); Lindsay (2014) Whitebox Geospatial Analysis Tools project, GIS Research UK conference, University of Glasgow.

## Summarized attachments

- **PDF-Instructions_DEM Processing and TWI** (`Instructions_DP6_DEM_Processing_TWI_v05.pdf`, file): Tutorial instructions prepared by Jibin Joseph and Venkatesh Merwade covering DEM preprocessing and Topographic Wetness Index generation. Explains necessity of DEM tiling/mosaicking, reprojection from geographic to projected coordinate systems (e.g., UTM), clipping to watershed boundaries, and TWI computation via Whitebox Tools. Details the five-step workflow: define variables and visualize tiles, merge/mosaic rasters, reproject to UTM, clip to study region, compute TWI via depression-filling (BreachDepressions), flow direction (D8), flow accumulation, slope, and WetnessIndex calculations.
- **PDF-Instructions_DEM Processing v02** (`Instructions_DP6_DEM_Processing_v02.pdf`, file): Version 2 tutorial instructions for DEM processing and topology analysis on the CyberFaCES or I-GUIDE platforms, covering raster merging, reprojection, and clipping workflows with code examples.
- **Instructions_DP6_DEM Processing v04** (`Instructions_DP6_DEM_Processing_v04.pdf`, file): Version 4 tutorial instructions for DEM processing and topographic analysis, representing a later iteration of the workflow documentation.
- **JN-DEM Processing and TWI** (https://github.com/I-GUIDE/hydroewd/blob/main/DEM_Process/Coursepage_DP6_DEM_Processing_v2d.ipynb, Jupyter notebook): Interactive notebook for DEM processing and TWI generation. Covers importing required packages (rasterio, geopandas, pywbt, pyproj), loading and visualizing unmerged DEM tiles with watershed shapefile overlay, merging tiles with rasterio.merge, coordinate system reprojection (geographic WGS84 to UTM), clipping rasters to watershed boundaries, and computing Topographic Wetness Index using Whitebox Tools functions (depression-filling, D8 flow direction, accumulation, slope). Generates output rasters: depression-filled DEM, D8 flow direction, downslope flowpath length, flow accumulation/specific contributing area (SCA), slope (degrees), and TWI. Produces comparison visualization grid of all six rasters.
