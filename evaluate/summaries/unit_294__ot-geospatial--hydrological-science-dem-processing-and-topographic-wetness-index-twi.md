# [OT] Geospatial & Hydrological Science: DEM Processing and Topographic Wetness Index (TWI)

Expert-level module built around one fetched Jupyter notebook, "Accessing and Processing Global DEM" (`Coursepage_DEMProcess_OT.ipynb`, GitHub repo jibcar/Miniworkshop_2025May, https://github.com/jibcar/Miniworkshop_2025May/blob/main/Coursepage_DEMProcess_OT.ipynb), prepared by Jibin Joseph and Venkatesh Merwade, Lyles School of Civil Engineering, Purdue University (joseph57@purdue.edu, vmerwade@purdue.edu), part of "FAIR Science in Water Resources."

Objective: end-to-end workflow for extracting a Topographic Wetness Index (TWI) raster anywhere on Earth — define a custom bounding box, pull DEM tiles on-the-fly from OpenTopography, reproject to a projected CRS, preprocess the DEM (breach depressions, flow direction, slope, specific contributing area) with WhiteboxTools via the PyWBT wrapper, then compute and visualize TWI for hydrologic or ecological analyses.

TWI theory: TWI (compound topographic index / wetness index) = ln(α / tan β), where α is specific upslope contributing area (m² m⁻¹, from a DEM flow-accumulation grid) and β is local slope angle in radians. Large contributing area increases TWI (wetter, saturated ground); steep slopes decrease it; flat valley bottoms have the highest values. Applications: predicting soil saturation and runoff generation zones, soil-moisture patterns for eco-hydrological models, delineating riparian buffers and wetland boundaries, explanatory variable in species-distribution or erosion studies. Notes: TWI is dimensionless and relative; sensitive to DEM quality, flow-routing algorithm, and slope estimation method.

Available OpenTopography global datasets (dropdown options): AW3D30 (ALOS World 3D 30m), AW3D30_E (Ellipsoidal 30m), COP30 / COP90 (Copernicus Global DSM 30m/90m), GEBCOIceTopo and GEBCOSubIceTopo (Global Bathymetry and Topography, 500m), GEDI_L3 (DTM 1000m), NASADEM, SRTMGL3 (SRTM GL3 90m), SRTMGL1 (30m), SRTMGL1_E (Ellipsoidal 30m), SRTM15Plus (Global Bathymetry SRTM15+ V2.1 500m).

Workflow steps and code: Step 0 imports requests, os, geopandas, pynhd (NLDI), matplotlib, rasterio and rasterio.plot, ipywidgets, urllib.request, progressbar, math, shapely.geometry.box, plus a shared module USGS_sites_map (`display_bounding_box`, `display_data_avail`) from /srv/shared/data_dem_access/, rasterio.warp (calculate_default_transform, reproject, Resampling), pyproj, tempfile, pathlib.Path, pywbt, numpy. Step 1: pick a DEM via ipywidgets Dropdown; define a bounding box (west, south, east, north; example boxes over Indiana and India), build a Shapely box in a GeoDataFrame (EPSG:4326), estimate UTM CRS with estimate_utm_crs (WGS 84), compute area in sq. m./sq. km. and warn if > 35,000 km² (kernel/RAM limit — use higher RAM or HPC); display data availability; build a unique filename from expanded bounding-box extents (bbox_to_filename with E/W/N/S hemisphere tags), producing `dem_<bbox>_<code>.tif`. Step 2: request GeoTIFF from the OpenTopography API (base URL https://portal.opentopography.org/API/globaldem, requires personal API_Key, demtype/south/north/west/east/outputFormat=GTiff parameters); handle HTTP status codes (200, 204 No Data, 400, 401, 403, 404, 408, 500); create folders with a check_create_path_func (~/scratch/DEM_Access, data subfolder, ./results); save and plot the DEM with rasterio/matplotlib (viridis colormap, elevation colorbar, bounding box overlaid in red). Step 3: reproject_raster_func reprojects the raster to the calculated UTM EPSG using calculate_default_transform and rasterio.warp.reproject with Resampling.nearest; plot reprojected DEM with Easting/Northing axes. Step 4: build a wbt_args dictionary of WhiteboxTools commands run in order by pywbt.whitebox_tools (input_dir, save_dir, max_procs=1, tempfile.TemporaryDirectory): BreachDepressions (--fill_pits; alternative to fill sinks — cuts through barriers so every cell drains), D8Pointer (D8 flow-direction grid), DownslopeFlowpathLength (downslope flow path length to outlet, for hydrologic indices and erosion models), D8FlowAccumulation (--out_type 'specific contributing area', SCA), Slope (--units=radians), WetnessIndex (TWI = ln(SCA/tan β)). Outputs named dem_corr_, fdir_, downslope_fp_length_, sca_, slope_, twi_ GeoTIFFs. Final plots: TWI raster (plasma colormap) and a 2x3 matplotlib panel of Reprojected DEM, Breach Depressions Filled Raster, D8 Flow Direction (index 1–128), Flow Accumulation/SCA (cells/meter), Slope (radians), and TWI (dimensionless), with 2–98 percentile stretch via numpy.
