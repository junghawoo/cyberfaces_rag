# Justice in Data: Metadata Creation

This unit focuses on the practical application of metadata creation in data stewardship and justice-oriented data practices through a hands-on activity centered on real-world hydrological data.

The primary resource is **DatasetForMetadataActivity.xlsx**, a file containing actual U.S. Geological Survey (USGS) water monitoring data for site 08057000 (Trinity River at Dallas, Texas). This dataset demonstrates the complexity and importance of proper metadata documentation for scientific data.

The embedded dataset spans from May 2022 through October 2022 and includes discharge measurements (cubic feet per second) tracked via radar, gage height (feet), specific conductance (microsiemens per centimeter at 25°C), dissolved oxygen (milligrams per liter), pH (standard units), water temperature (degrees Celsius), and turbidity measurements (formazin nephelometric units or FNU) using monochrome near-infrared LED light detection.

Key metadata elements preserved in the source data include: location coordinates (Latitude 32°46'29", Longitude 96°49'18" NAD27), drainage basin information (6,106 square miles total contributing area), gage datum elevation (367.84 feet above NAVD88), collection site identifiers (USGS 08057000), parameter codes and statistic types (maximum, minimum, mean, median), and temporal records spanning multiple months with timestamps.

Data quality indicators embedded within the dataset include qualification codes distinguishing between "Approved for publication" data (code A) and "Provisional data subject to revision" (code P). The dataset warns that provisional data are released subject to revision and that neither the USGS nor the U.S. Government may be held liable for damages from its use.

The metadata includes extensive information about data retrieval and file format specifications, with references to USGS help documentation (https://help.waterdata.usgs.gov/). The dataset demonstrates how real scientific data integrates technical specifications, uncertainty communication, and access policies—all foundational concepts for understanding data justice, transparency, and responsible data stewardship.

This activity teaches learners to recognize and create metadata that addresses both technical data specifications and ethical dimensions of data sharing, including attribution, provenance, limitations, and intended use.
