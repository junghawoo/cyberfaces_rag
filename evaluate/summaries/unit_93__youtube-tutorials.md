# YouTube tutorials

This unit aggregates three foundational YouTube video tutorials for learning R programming and data science:

**1. Data Science with R (Dave Langer, Microsoft):**
Tutorial series using R for data analysis and predictive modeling with Titanic dataset (Kaggle competition). Demonstrates reading CSV files via read.csv(), data frame manipulation, combining train/test datasets with rbind(), converting data types to factors, conducting survival rate analysis using table() function, and visualizing patterns with ggplot2 package. Covers feature engineering from character strings (extracting title prefixes "Miss," "Mrs," "Master," "Mr." from passenger names), understanding survival bias, and the women-and-children-first evacuation pattern through bar plots and facet_wrap visualizations. Libraries: ggplot2, stringr for pattern detection. Discusses underfitting vs. overfitting, importance of domain understanding, and practical data exploration workflow (head, str functions). Emphasizes R community resources (CRAN packages), RStudio IDE, and machine learning as prediction vs. backward-looking business intelligence.

**2. Introduction to R (Philip, DataCamp):**
Basics-focused video covering R as language for statistical computing, DIKW pyramid (Data-Information-Knowledge-Wisdom), RStudio console, variable assignment using <- operator, workspace management with ls(), data frames, matrix operations, read.csv(), data structure inspection via str() function, factors for categorical data, factors vs. character strings, and basic statistical operations (mean, median, histogram plots, correlation). Highlights R's specialization in visualization, open-source packages, and community extensions compared to point-and-click alternatives.

**3. Why R is Popular (Unknown Presenter):**
Survey video explaining R's adoption in academic and commercial settings: free open-source vs. expensive proprietary alternatives (SPSS, Stata, SAS), reproducibility and collaboration via code-based analysis, pattern discovery from large datasets, advanced visualization and graphics capabilities superior to competing packages, access to thousands of community-developed packages, machine learning and AI integration, and transition from traditional business intelligence to data-driven analytics. Demonstrates simple operations: applying functions to objects (mean, median, hist, plot, correlation tests on dataset variables).

**Key Takeaways:** R specializes in statistical analysis, visualization, and reproducible research; RStudio IDE enhances usability; Kaggle provides real-world datasets for practice; data exploration and visualization precede modeling; character and factor data types require careful handling for analysis.

## Summarized attachments

- **Data Science with R** (https://www.youtube.com/watch?v=32o0DnuRjfg, YouTube video): Long-form tutorial by Dave Langer (Microsoft) demonstrating practical data science workflow using R on the Titanic Kaggle competition dataset. Covers downloading train/test CSV files from Kaggle, loading data via read.csv(), manipulating data frames with rbind() for combining datasets, converting data types to factors, conducting exploratory analysis with table() function, extracting features from character strings (passenger titles "Miss"/"Mrs"/"Master"/"Mr." from names), creating visualizations with ggplot2 and facet_wrap() to reveal gender/class survival bias patterns, and discusses machine learning concepts (underfitting, overfitting, domain understanding). Approximately 120+ minutes comprehensive walkthrough; assumes R and RStudio already installed.

- **Introduction to R** (https://www.youtube.com/watch?v=SWxoJqTqo08, YouTube video): Shorter foundational video by Philip (DataCamp) introducing R as a language for statistical computing and data science. Covers RStudio console basics, variable assignment using the `<-` operator, workspace management with ls(), data frames, basic operations (mean, median, histogram, correlation), and encourages viewers to explore Kaggle datasets and Kaggle competitions for hands-on practice. Suitable for absolute beginners.

- **Why R is Popular** (https://www.youtube.com/watch?v=9kYUGMg_14s, YouTube video): Survey video (presenter unknown) explaining R's adoption in academic and commercial settings, emphasizing R's advantages: free and open-source vs. expensive proprietary alternatives (SPSS, Stata, SAS); reproducible, code-based analysis enabling collaboration; discovery of patterns in large datasets; superior visualization and graphics capabilities compared to competing packages; access to thousands of community-developed packages; machine learning and AI integration; and the transition from traditional business intelligence to data-driven analytics. Includes brief live demonstrations of basic R operations (mean, median, histogram, correlation tests).
