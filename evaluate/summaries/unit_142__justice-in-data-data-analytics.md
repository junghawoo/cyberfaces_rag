# Justice in Data: Data Anlytics

Foundation module of the Justice in Data boot camp introducing data analytics with Python, taught by instructor Jessica via lecture slides, a pre-survey, and a recorded hands-on session on the myGeoHub Jupyter Notebook platform.

**Data Analytics Slides** (source file `Data_Analytics.pdf`): introduction to data analytics, types of data analytics, and the data analytics process steps. Covers descriptive statistics (describing a population via numerical calculations, graphs, tables) and the commonly used statistics: mean, median, max, min, standard deviation. Introduces Python libraries for data analytics: **Pandas** (built on **NumPy**), with its two data structures — Series (one-dimensional labeled array; like an Excel column) and DataFrame (two-dimensional, size-mutable, heterogeneous tabular structure with labeled rows/columns) — plus hands-on Python exercises.

**Data Analytics Pre-Survey** (link): QuestionPro survey (utaedu.questionpro.com).

**Data Analytics Recording** (link, YouTube video M2uEDMOYXPQ): full workshop session transcript. Concepts: three types of analytics — descriptive (what happened), predictive (what will happen), and prescriptive (how to make something happen) — with a furniture-sales example; five analytics steps (data collection, data preparation/pre-processing, data exploration, data modeling, interpretation); measures of center (mean, median, mode) and spread (range, interquartile range, variance, standard deviation); exceedance probability charts for streamflow/discharge in water resources engineering; pandas vs scikit-learn vs NumPy analogies. **Activity 1** uses a precipitation CSV (e.g., Bear/state precipitation data, 1826 rows): `import pandas as pd`, `df.info`, `df.shape`, filtering rows where precipitation > 0 (432 days) or == 9.4 mm, `df.iloc` index-slicing (first 1000 rows, rows 20–100), `df.max`, `idxmax`, `idxmin`, `df.std` (10.848), mean (3.13), median, NumPy sums (total 5722 mm), counting values greater/less than 10; exercise computing min/mean/max/std/median of the first 200 rows (mean 4.637, std 11.328, max 83.8). **Activity 2** computes the coefficient of determination (r-squared / correlation coefficient) between two temperature datasets (temp1, temp2) using `r2_score` from **sklearn (scikit-learn)**, renaming unnamed columns, `pd.concat` to combine DataFrames, `drop` with axis=1, r² = 0.775 (0.7909 for first 200 rows; negative correlation for rows 20–100), saving with `to_csv` to combine_temp.csv, and separating combined DataFrames. **Activity 3** loops over multiple CSVs: `os.getcwd`, `os.chdir`, `glob` with wildcard patterns (`*.csv`, `data_*`), a for-loop appending r² values to a list (`r_values.append`), `type()` checks, converting lists to DataFrames (`pd.DataFrame`, column "R2"), and normalizing data with `sklearn.preprocessing.normalize`; discusses skewness (positive/negative), normal distributions, statistical-test assumptions (normality, independence, identically distributed residuals). **Activity 4** covers linear regression as predictive analytics: `scipy.stats.linregress` returning slope (0.87), intercept (5.9), r (0.96), p-value (< 0.05), standard error (0.012); building a y = mx + b prediction function; plotting raw data, regression line, and residuals with **matplotlib**; then the **statsmodels** API (`import statsmodels.api as sm`), `sm.add_constant`, ordinary least squares `sm.OLS(...).fit()`, `model.predict(x)`, and interpreting `model.summary()` output (R-squared 0.931, adjusted R-squared, coefficients, standard errors, t-values, p-values, 95% confidence intervals, skew). Practical Jupyter/myGeoHub tips throughout: kernel restarts, terminating extra sessions from the dashboard, Ctrl+Enter to run cells, Cell > Run All, and annual-mean filtering with datetime types.
