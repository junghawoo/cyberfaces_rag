# R

Foundation module introducing the R programming language and how R software can be made FAIR (Findable, Accessible, Interoperable, Reusable). The text content ("What is R and how can it be FAIR?") describes R as a programming language and software environment for statistical analysis and graphical data that is easy to find, accessible, modifiable, and reusable, with easy commenting and sharing of projects and data.

External resources:

- **FAIR-ifying R Software** (tibhannover.github.io/FAIR-R/): a lesson interpreting the FAIR principles for software source code, teaching good programming practices — creating functions, documenting, packaging, and testing. Based on the Software Carpentry lesson swcarpentry/r-novice-inflammation (a fictional daily patient inflammation study using CSV data). Recommends RStudio. Lesson schedule: Introduction to RStudio (GUI usage); Preparations (reading data into R, assigning variables, data frames, mean/median statistics, getting help, plotting); Creating Functions (making, manually testing, and documenting functions); Making Packages in R (collecting code for reuse/sharing, integrating documentation into R's help pages, RStudio helper tools); Unit-Testing and Test-Driven Development (creating and running unit tests); Tidying & Packaging Datasets (dataset forms, reusability features, adding datasets to R packages).

- **Introduction & Basics of R** (guru99.com r-programming-introduction-basics): R was developed by Ross Ihaka and Robert Gentleman in 1993; used by Uber, Google, Airbnb, Facebook; heavy computation delegated to C, C++, Fortran. Data-analysis workflow: program, transform, discover, model, communicate (R Markdown reports, Shiny apps, hosting on Rpub, GitHub; export to HTML, PDF/LaTeX, Word, PDF beamer). ~12k libraries stored on CRAN. Compares R with Excel, PowerBI, Python, SAS, and Tableau for data science, statistics, machine learning, and DataViz; cites Stack Overflow question trends. Mentions Hadley Wickham's tidyverse for data manipulation, Keras, TensorFlow, and Xgboost (Kaggle) packages, interoperability with Python/Java/C++, database connections to Spark and Hadoop, and the parallel package for multi-core computation. Related articles: installing RStudio in Anaconda (Windows/Mac), R data types, for loops, bar charts and histograms.
