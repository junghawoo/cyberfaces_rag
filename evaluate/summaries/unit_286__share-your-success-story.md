# Share Your Success Story

Expert-level course container bundling two Purdue ITaP/RCAC Research Computing workshop resources plus OCR and external items.

**Biocontainers 101 — Using Containers in Bioinformatics** (`biocontainers101.pdf`): by Yucheng Zhang (Senior Life Science Scientist, ITaP Research Computing) and Lev Gorenstein, ITaP Research Computing Virtual Workshop Series, Feb. 25, 2022. Covers what containers are (portable, reproducible software environments; container images and registries), why to use them on clusters (bypassing old cluster OS/GLIBC library limits). History: containers from the 1970s, Docker (2013, needs root/superuser — HPC security concern), Singularity (2015, Lawrence Berkeley National Laboratory, Gregory Kurtzer; no root privileges, can run Docker images). Singularity basics and subcommands: build, pull, shell, exec; user guide at sylabs.io/guides/3.8/user-guide. HPC workflow (build with root on personal machine, pull/transfer to HPC, run). `singularity pull` from URIs: library://, docker:// (Docker Hub, Quay.io), http(s), with --disable-cache tip. Registries: Docker Hub (8,842,825 images as of Feb 17 2022), BioContainers (biocontainers.pro; Bioconda index; 10.6K tools), Galaxy project depot. Example: pulling bowtie2 from Docker Hub, Bioconda/Quay.io, and Galaxy. `singularity shell`, bind mounts (--bind; default $HOME, /tmp, $PWD; RCAC also binds /apps, /depot, /scratch), and `singularity exec` (BLAST blastx example vs swissprot/nr). RCAC Biocontainers as modulefiles: `module load biocontainers` then bamtools/2.5.1, alphafold/2.1.1 (AlphaFold, DeepMind; ~2.2TB full DB, run_alphafold.sh, $AlphaDB), homer/4.11 (motif discovery/next-gen sequencing; organisms and genomes hg19/hg38/mm10 etc.), gtdbtk/1.7.0 (GTDB-Tk taxonomic classification, R202 data; identify/align/classify), humann/3.0.0 (HUMAnN with ChocoPhlAn, UniRef90/50, utility_mapping DBs), run_dbcan/3.0.2 (CAZyme annotation; CAZyDB, dbCAN-HMMdb-V10), r-rnaseq/4.1.1-1 and r-scrnaseq/4.1.1-1 (customized R containers with DESeq2, edgeR, limma, ComplexHeatmap, Seurat, monocle3, SingleR, DropletUtils, etc., built on Lev Gorenstein's r/4.1.1 base). Building your own: singularity 3.8.0, `sudo singularity build image.sif image.def`, Sylabs Remote Builder (cloud.sylabs.io, access token, `singularity remote login`, build -r/--remote). Definition (.def) files (Header + %labels/%help/%post/%environment sections); bootstrap agents library/docker/localimage. Example def files: ANGSD v0.935 (from ubuntu:20.04, htslib, samtools), aTRAM v2.4.3 (from continuumio/miniconda3, bioconda blast/velvet/trinity/abyss/spades/exonerate), R containers from localimage (tidyverse, BiocManager, Seurat, monocle3). Support: rcac-help@purdue.edu, RCAC Coffee Hour Consultations (rcac.purdue.edu/coffee), contact zhan4429@purdue.edu or lev@purdue.edu.

**Introduction to QGIS** (`introduction.md`, Carpentries-style lesson, teaching 10 / exercises 3): objectives cover why QGIS, starting QGIS on HPC clusters, loading/visualizing data, and processing/exporting. QGIS is free, open-source, cross-platform (macOS/Windows/Linux), supporting Shapefile, GeoTIFF, GeoJSON, WMS, WFS, PostGIS, plus AI/GeoAI integration. Starting QGIS on clusters via ThinLinc (interactive "Cluster Software" job on the "workshop" queue, or terminal: `module spider qgis`, `sinteractive -A workshop`, `module load qgis`, `qgis`) or via Gateway/Open OnDemand (Negishi Gateway). Vector data (points/lines/polygons; Shapefile .shp/.shx/.dbf, GeoJSON, KML/KMZ; handled by GDAL/OGR) vs raster data (grid/pixels; TIFF, GeoTIFF, COG Cloud Optimized GeoTIFF). Hands-on: loading vector layers (alaska.shp, airports.shp), delimited-text/CSV layers, raster layers (landcover.img, SR_50M_alaska_nad.tif hillshade), CRS handling from .prj files (cites Graser et al., 2017). Processing examples: filtering airports by ELEV field (<1000 ft), exporting via Save Features As, and Raster Calculator (hillshade < 100 for sunny slopes). Keypoints reiterate QGIS is free/open-source and usable on HPC via ThinLinc or Gateway.

## Summarized attachments

- **Biocontainers 101: Using Containers in Bioinformatics** (`biocontainers101.pdf`, PDF): Comprehensive workshop on containerization for HPC by Yucheng Zhang and Lev Gorenstein covering what containers are, why to use them on clusters, Docker vs Singularity (no root needed), singularity pull/shell/exec commands, three major container registries (Docker Hub, BioContainers, Galaxy), and RCAC pre-deployed biocontainers with examples (alphafold, homer, gtdbtk, humann, run_dbcan, r-rnaseq, r-scrnaseq).
- **Introduction to QGIS** (`introduction.md`, markdown): Foundation-level introduction to QGIS (free, open-source GIS software) covering why to use it, how to start QGIS on HPC clusters via ThinLinc or Gateway, vector vs. raster data formats, loading and visualizing spatial data (shapefiles, CSV, rasters), and processing tasks like filtering and raster calculations.
