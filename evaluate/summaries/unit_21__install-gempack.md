# Install Gempack

Tutorial on GEMPACK installation for computable general equilibrium (CGE) modeling.

GEMPACK components: Command-line programs (recompilable for most computers); GUI programs (Windows-only: ViewHAR, TABmate, AnalyseGE, GTAPAgg, RunGTAP).

Mac OS X installation: GEMPACK for Mac OS X wrapper (by Joe Francois, Wine/WineSkin-based). Requirements: Intel-based Mac, Snow Leopard (OS X 10.6) or later. Usage options: Executable-image GEMPACK with GUI programs, GTAP-related programs (RunGTAP, GTAPAgg), viewing programs (ViewHAR, ViewSOL, AnalyseGE) with source-code version. Caveats: Program behavior similar but not identical to Windows; limited support; volunteer effort.

Installation steps: Download GPMacOSX.PDF documentation; drag GEMPACK file to applications directory; drag GEMPACK Apps folder to applications directory.

Pre-course installation: Install BEFORE course to identify problems early when instructors have time. Requirement: Administrator access rights (may need IT department help on corporate machines). Version: GEMPACK Release 11.0 or later required (check via Help...GEMPACK licence in TABmate/ViewHAR).

Downloading and installing Executable-Image Version: (1) Read quickinst.pdf (simplified training course instructions); (2) Download Limited Executable-Image Version Trial Edition; (3) Follow QuickInst (not longer GPInstall.pdf); (4) Complete Section 3 model simulation test to verify installation.

Trial Edition details: Includes all main GEMPACK programs; full range of modeling tasks; model size limitations acceptable for training; temporary 6-month license from download date (sufficient for course); longer license often provided during course.

Additional software: RunDynam (dynamic simulations), RunGTAP (GTAP model solving) may be pre-installed; install GEMPACK first (dependencies). Practical GE course: requires MINIMAL free training software.

Course materials: Course CD/USB key provided (contains software, exercises, supplementary material) — use after course, install necessary software before course.

License upgrade: Trial edition temporary (6 months); course participants often receive course-specific license (12 months from course start, email or on-site).

Requirements: Laptop specifications (see docs), Executable-Image GEMPACK, Training course page information.

References: GEMPACK Home Page, Versions of GEMPACK.
