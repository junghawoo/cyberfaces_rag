# Justice in Data: Data Usage Licensing

Course on data licensing and usage rights. Objectives: understand importance of data licensing; compare/contrast typical data licenses. Presentation: Data_License.pdf.

Background: Legitimate reasons to restrict public-funded data/services access (privacy, national security, competitiveness). Data owner discretion on availability. FAIR principles require clarity/transparency on access/reuse conditions. FAIR ≠ Open; FAIR = Accessible under well-defined conditions.

Data license definition: Legal arrangement between data creator and end-user specifying permitted uses. Benefits: reduces uncertainty, reduces ambiguity, enables mining, reuse, combination, redistribution.

License types:

Creative Commons (CC): Most common, irrevocable copyright licenses. Types: CC-BY (commercial/remix allowed, attribution required); CC-BY-SA (commercial/remix, attribution required, derivative same license); CC-BY-ND (commercial allowed, no derivatives, attribution required); CC-BY-NC (non-commercial remix, attribution required); CC-BY-NC-SA (non-commercial, derivative same license, attribution required); CC-BY-NC-ND (most restrictive, non-commercial, no changes, attribution required); CC0 (public domain, creator relinquishes rights).

Open Data Commons: Legal tools for data sharing. Licenses: PDDL (Public Domain Dedication and License, unrestricted use/modify/distribute), ODC-By (Attribution License, requires attribution), ODbL (Open Database License, database-specific, requires attribution and share-alike on modifications).

Proprietary License: Exclusive rights to software/data; restricts use/distribution; examples: Microsoft Windows, Skype, Adobe Photoshop.

End User License Agreement (EULA): Legal agreement between vendor and user; defines terms/conditions; presented during installation; requires acceptance before use.

MIT License: Open-source; permissive (any use including commercial); allows modification (with original copyright notice), redistribution; compatible with other open-source licenses.

Comparison: Creative Commons/Open Data Commons/MIT (open, allow modification, require attribution, compatible with open-source); Proprietary/EULA (restrict use, usually restrict modification, variable attribution, incompatible with open-source); Scope: CC/ODC for text/images/data; MIT for software; Proprietary/EULA for both.

License selection approach: (1) Research before selecting; (2) Determine if data can be released publicly; (3) Ask questions (Terms of Service, copyright, contractual restrictions, copyright holders, institutional policies); (4) Check community practice (most DataCite DOI datasets use CC licenses); (5) Select understood license with clear terms; (6) Declare license in data repository. Public domain licenses (CC0) acceptable with suggested citation metadata.
