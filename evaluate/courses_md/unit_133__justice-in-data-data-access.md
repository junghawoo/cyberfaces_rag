Data Access
●
Data access is the on-demand, authorized ability to retrieve, modify, copy, or move 
data from IT systems.
●
Data access is the means by which users can get data and its location, in an 
authenticated manner approved by the organization in possession of the data.
Python is incredibly flexible and has a lot of open-
source libraries for accessing and processing data. 
3 main categories from where data is accessed:
1. Local files
2. Databases
3. Application Programming Interfaces (APIs)
3

Data Access
●Local files which are available on your system.
●A database is an organized collection of structured information, or data, 
typically stored electronically in a computer system. A database is 
usually controlled by a database management system (DBMS). 
Together, the data and the DBMS, along with the applications that are 
associated with them, are referred to as a database system.

What is a netCDF file ?
●
NetCDF (network Common Data Form) is a file format for storing multidimensional scientific
data (variables) such as temperature, humidity, pressure, wind speed, and direction.
●
Each of these variables can be displayed through a dimension (such as time) in ArcGIS by
making a layer or table view from the netCDF file.

Repository vs Large Scale Database.
Building Genome data is a singular CSV file for raw data. 
Why?
1.
This Data is not updated very often
○
It’s purpose as a test case warrants it to not change often.
2. As it does not need to be updated often it 
can be hosted as a singular file on a repository instead of a 
larger database.
○
In this case, the data is hosted on GitHub.
