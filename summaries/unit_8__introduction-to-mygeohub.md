# Introduction to MyGeoHub

MyGeoHub overview and basics tutorial. Web portal: http://mygeohub.org. Presentations by Carol Song (Senior Research Scientist, RCAC, Purdue University) and Lan Zhang, FACT Fellows Webinar Series (June 5, 2020). Video: CyberTraining Webinar 2-20200605.

MyGeoHub purpose: Interactive data access, visualization, exploration; publishing/sharing data, tools, modeling/analysis; collaboration, dissemination; active learning.

Active learning courses: EAPS DataMine FAIR Climate Data Course, FAIR Climate and Water Science, Global Change and Sustainably Feeding Growing Planet, RWater Cyber-enabled Hydrology Tool, Multi-scale Sustainability Analysis Short Course, Geospatial Data Extraction and Visualization Short Course.

Key characteristics: Science gateway/portal; open access (worldwide); low barrier of entry (web browser only, no installation/programming expertise); open source; supports FAIR science (Findable, Accessible, Interoperable, Reusable); increased transparency, reproducibility; vibrant community sharing models, tools, datasets, best practices.

Cyberinfrastructure: Web server, HUBzero-based, multiple execution hosts (campus clusters, national computing resources), Geoserver, load balancing.

HUBzero platform: 60+ known hubs/science gateways across domains (science, engineering, humanities, healthcare). nanoHUB.org (~15 years, NSF-funded, 1.5M annual visitors, 500+ tools). MyGeoHub (~5 years, 10,000+ annual users as of 2020, NSF data infrastructure funding, new NSF GeoEDF project for scientific model/tool integration with datasets).

MyGeoHub basics:

Login options: Multiple authentication methods available.

Dashboard: Landing page post-login; configurable modules for easy navigation and quick access.

Navigation: Homepage (supergroups, menus), Dashboard (tools, groups, projects, sessions, drafts), Supergroup landing pages (supergroup-specific info).

Groups and Projects: Groups enable collaborators to share data/information (wiki, forum, blog, projects, course, announcements). Projects organize/share data within groups (iData, DOI data publication).

Course features: Browse catalog, interactive materials (lecture notes, assignments, tool launch, data download, progress tracking, discussions).

Collaboration: Wiki posts, blog entries, iData (data management/quick view), data publication with DOI, tickets (submit via ? at top right).

Support: Contact zhao4@purdue.edu, cxsong@purdue.edu. Wiki help: https://mygeohub.org/wiki/Help:WikiFormatting?tmpl=component.

Hands-on activities: Configure dashboard, launch tools, browse resources, navigate supergroups, access FAIR groups/projects, create wiki/blog entries, enroll/create courses.

Award: NSF OAC-1261727 (MyGeoHub infrastructure).

Expert-level resource for geospatial collaboration and FAIR science practices.
