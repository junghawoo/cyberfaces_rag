# Introduction to Python

Foundation-level introduction to Python programming basics.

Python as calculator: Arithmetic operations (addition, multiplication, subtraction, division). Integer type: 2+2=4, 4*30=120 (whole numbers). Float type: (50-5*6)/4=5.0 (division produces floating-point numbers). Notebook execution: Shift-Enter to evaluate cells in Jupyter/IPython.

Variables: Define using equals sign (=). Examples: width=20, length=30, area=600. Naming rules: start with letter or underscore (_), alphanumeric characters and underscores allowed. Reserved words prohibited: and, as, assert, break, class, continue, def, del, elif, else, except, exec, finally, for, from, global, if, import, in, is, lambda, not, or, pass, print, raise, return, try, while, with, yield.

Error handling: Accessing undefined variables produces errors; variables must be defined before use.

Resources: Python Tutorial (http://docs.python.org/3/tutorial/introduction.html — using Python as interactive shell), IPython tutorial (ipython.readthedocs.io — sophisticated interactive shell), Jupyter Notebook Exercise (GitHub: https://github.com/nujwoo/python101/01cal.ipynb).

Python.org Getting Started (https://www.python.org/about/gettingstarted/):

Audience: Completely new to programming or experienced programmers. Easy to learn for beginners; quickly learned by experienced programmers.

Installation: Generally easy; many Linux/UNIX distributions and Windows systems (HP) include Python pre-installed. Resources: BeginnersGuide/Download wiki (platform-specific notes).

Learning paths: IDEs and text editors (Python editing), introductory books, code samples. Experienced programmers: BeginnersGuide/Tutorials page, resources in other languages. Documentation: online docs, brief tutorial (basics), library reference (complete), language reference (syntax).

References: ActiveState Python Cookbook (recipes/patterns), Python Package Index (libraries/applications), search pages, Google, python newsgroup.

Support: FAQ (frequently asked questions), developer area (contributing to Python), Python Software Foundation (PSF) — membership available to help advance Python.

Foundation level content suitable for absolute beginners with no programming experience.
