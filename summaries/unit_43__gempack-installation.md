# GEMPACK installation and user manual

Foundation-level module on installing GEMPACK (the General Equilibrium Modelling PACKage for CGE modelling) and using its official documentation. It contains three fetched web resources from copsmodels.com plus one non-text attachment.

**Resource 1 — "GEMPACK Documentaiton" (link, https://www.copsmodels.com/gpmanual.htm): the GEMPACK User Manual.** Authored by Mark Horridge, Michael Jerie, Dean Mustakinov, and Florian Schiffmann (31 Dec 2024, ISBN 978-1-921654-90-9; citation ISBN 978-1-921654-34-3), published by GEMPACK Software, Centre of Policy Studies, Victoria University, Melbourne, with acknowledgment of earlier manual authors Ken Pearson and Jill Harrison; covers GEMPACK Release 12.2 and later. The extract includes the Brief and Detailed Tables of Contents for all 83 chapters (with green "topic IDs" like gpd1.1, harfiles, condense) and full text through roughly chapter 9 (truncated). Chapter topics: 1 Introduction (manual organization, supported operating systems, command-line vs Windows vs TABLO-generated programs, supplied models, licence versions — source-code, unlimited/limited executable-image, introductory licence, activation, citing GEMPACK, GEMPACK web site and GEMPACK-L mailing list, training courses); 2 Installing GEMPACK on Windows PCs (system requirements: Windows 7+, 2GB disk, 4–8GB RAM; licence file; install directory; IT-support notes; testing the Fortran installation; anti-virus configuration; PATH/environment changes; install packages named like gpei-12.0-000-install.exe and gpsc-12.0-000-install.exe); 3 carrying out simulations; 4 building or modifying models; 5 Header Array (HAR) files; 6 constructing HAR files; 7 GEMPACK file types, names and suffixes; 8–11 running TABLO and TABLO-language syntax/semantics; 12–13 post-simulation processing and ranking sets (winners/losers); 14 condensing models; 15 verifying models; 16 intertemporal models; 17 less obvious TABLO examples; 18 linearizing levels equations; 19–35 simulation reference: Command (CMF) files, TABLO input and auxiliary files, CMF statements for data/updated/display files, specifying closure and shocks, GEMSIM and TABLO-generated program actions, multi-step solution methods, Solution (SL4) files, SLC/UDC/AVC/CVL files, subtotals, simulation time, parallel solving on multiprocessors, memory management, options, run-time errors, command-file statement summary; 36 GEMPACK Windows programs; 37 command-line programs for header array files; 38 GEMPACK text data file syntax; 39–40 SLTOHT for processing results and spreadsheets; 41 ACCUM and DEVIA (accumulation/differences); 42–46 hands-on tutorials (WinGEM getting started, command-prompt computing, RunGEM simulations, AnalyseGE result analysis); 48–79 advanced topics: command-line workflow, code options in TABLO, complementarities, MODHAR, variable/equation ordering, SEENV closure viewing, automated homogeneity testing, SAGEM simultaneous Johansen simulations, Equations/LU files, example models, pivoting and memory-sharing strategies, executable-image size limits, technical details, legacy features, interactive variable selection, older closure/shock methods, improving TAB and CMF files, RunDynam shock statements, GEMPACK on Linux/Unix/Mac OS X, TEXTBI (extracting TAB/STI/CMF from AXT/SL4/CVL files), GEMPACK history, TABLO-generated vs GEMSIM timing, Fortran compilers for source-code GEMPACK, LTG variants and compiler options, HAR fine print, binary-file conversion (LF90/F77L3 to/from Intel/LF95/GFortran), GEMPACK–GAMS (GDX/HAR) data translation, recent GEMPACK with older RunGTAP/RunDynam, SUMEQ; Cites GPmanual.pdf for printing. Named GUI tools throughout: ViewHAR, ViewSOL, TABmate, AnalyseGE, WinGEM, RunGEM; core engines TABLO.EXE and GEMSIM.EXE.

**Resource 2 — "GEMPACK for Mac users" (link, https://www.copsmodels.com/gpmacosx.htm): GEMPACK for Mac OS X.** A wrapper by Joe Francois running GEMPACK GUI programs (ViewHAR, TABmate, AnalyseGE, ViewSOL, GTAPAgg, RunGTAP) via Wine (WineSkin) on Intel Macs with Snow Leopard (OS X 10.6)+; last updated 10 June 2013, no longer supported. Covers install (drag GEMPACK and GEMPACK Apps to Applications; read GPMacOSX.PDF), GTAP database licences, native source-code command-line use via Terminal, and Wine caveats.

## Summarized attachments

- **GEMPACK Documentaiton** (https://www.copsmodels.com/gpmanual.htm, link): The GEMPACK User Manual covering Release 12.2+ with 83 chapters on Windows and command-line installation, TABLO programming language syntax and semantics, simulation methodology using the Stylized Johansen model, post-processing and result analysis, and advanced techniques including intertemporal models, complementarities, and multi-processor solving. Authored by Mark Horridge, Michael Jerie, Dean Mustakinov, and Florian Schiffmann (2024).

- **GEMPACK for Mac users** (https://www.copsmodels.com/gpmacosx.htm, link): A wrapper package by Joe Francois (last updated June 2013, no longer officially supported) enabling GEMPACK GUI tools including ViewHAR, TABmate, AnalyseGE, and ViewSOL to run on Intel Macs via Wine/WineSkin. Covers installation procedures, GTAP database setup, native command-line terminal usage, and Wine-specific caveats.

- **Get the software!** (https://www.copsmodels.com/gplapsoft.htm, link): Pre-course installation guide for GEMPACK on training laptops requiring Release 11.0+, administrator access rights, and covering the Trial Edition with 6-month temporary licenses. Provides simplified QuickInst.pdf instructions, verification procedures via model simulation, and optional installation of RunDynam and RunGTAP programs.

- **Installing GEMPACK.zip** (Installing GEMPACK.zip, zip): No machine-readable content extracted.
