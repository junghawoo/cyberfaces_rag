# Justice in Data: Introduction to Databases and Data Storage

Foundation module in the Justice in Data course introducing databases and data storage, taught by Professor Sharma Chakravarthy (University of Texas at Arlington, UTA). The core resource is the slide deck "Introduction to Databases and Data Storage Slides" (source file `CTW-intro-databases-storage_FINAL.pdf`), supplemented by an "Introduction to Databases and Data Storage Pre-Survey" (QuestionPro link), and two YouTube lecture recordings: "Introduction to Databases and Data Storage Recording" and "Multi-Source Data Analysis Recording."

**Multi-source data analysis and the CoWiz++ dashboard.** The slides open with a case study of the CoWiz/CoWiz++ COVID-19 visualization dashboard built at UTA's IT Lab (https://itlab.uta.edu/CoWiz/; demo videos on YouTube). It analyzes US county-level COVID data with base-period vs. target-period event analysis (e.g., Thanksgiving weekend 2020), severity rate classification (spike/uptick/flat/downtick), and geographic/temporal/event/parameter-based aggregate visualizations. Data sources covered: CDC daily COVID cases/deaths/tests/hospitalizations, Our World in Data (OWID) vaccinations, US Department of Transportation Trips by Distance (Maryland Transportation Institute, Bureau of Transportation Statistics), and Google Community Mobility Reports. Pre-processing challenges discussed: delimiters, date/temperature/unit formats, state NAME/CODE/FIPS encoding, missing values, join attributes (State, Date), merged data files, configuration files to avoid hardcoding, crontab-scheduled web crawls, on-demand API calls, and a modular dashboard architecture (client, visualization management, data analysis modules).

**Why Python for data analysis.** Comparison of Python, R, RStudio, and Pandas: data frames in both languages, R's pipes and cluster package vs. Python's scikit-learn, web scraping with rvest (R) vs. BeautifulSoup (Python), NumPy for vector/matrix operations, Pandas' R-like DataFrames, main-memory scalability limits vs. SQL, and Python's "batteries included" ecosystem (flask, django, matplotlib mentioned in the recording).

**Files vs. DBMS.** Record formats (fixed length, system catalogs), problems of file-based applications (format coupling, duplication, concurrency, recovery, querying), a 1970s payroll/tape-drive example, and data repositories: data warehouse, data lake, data marts, Git/GitHub. GIS data repositories listed: Natural Earth, USGS Earth Explorer, OpenStreetMap, Esri Open Data Hub, NASA SEDAC (Socioeconomic Data and Applications Center), OpenTopography (LiDAR), NASA Earth Observations (NEO).

**Data models and relational DBMS.** Hierarchical, network, and relational models; EER (Extended Entity Relationship) modeling with an example EER diagram for company founders (Erwin tool mentioned); UML (OMG standard) for GIS design, exporting Workspace XML into a geodatabase (GDB) via ArcCatalog. Relational model concepts: schema (intension) vs. extension, Students/Enrolled CREATE TABLE examples, SQL non-procedural querying, query optimization, levels of abstraction (views, conceptual schema, physical schema, DDL/DML), ACID properties, OLTP/OLAP, data warehouses with CUBE/ROLLUP, Big Data 4 V's (volume, velocity, variety, veracity). Commercial DBMSs: Oracle, DB2 (IBM), SQLServer (Microsoft), Sybase; open source MySQL and Postgres. Column-oriented SQL databases: Vertica (geospatial ST_intersects/STV_intersects, shapefile loading), SybaseIQ (SAP), Apache HBase, MonetDB, MariaDB. Also mentioned: MyMav (UTA's Oracle-based registration system), "Is the WWW a DBMS?" and "Is a File System a DBMS?" thought experiments.

**GIS and ArcGIS.** Definitions of GIS from USGS and ESRI; an African conflict index table (1966–78, Anselin and O'Loughlin 1992) motivating spatial clustering questions and spatial databases; GIS software: ArcGIS (ESRI; ArcMap, ArcCatalog, ArcToolbox, ArcScene, ArcGlobe, ArcGIS Pro; extensions 3D Analyst, Spatial Analyst, Network Analyst, Survey Analyst, Tracking Analyst, Geostatistical Analyst) vs. QGIS and GRASS; geodatabases backed by IBM Db2, Microsoft SQL Server, Oracle, PostgreSQL, or SAP HANA; vector vs. raster data, attribute data, and metadata.

**NoSQL databases.** Motivation (scaling out at Google, Facebook, Amazon), history (Carlo Strozzi 1998, Neo4j 2000, Google BigTable 2004, CouchDB 2005, Amazon Dynamo 2007, Facebook Cassandra 2008), characteristics (schema-less, sharding, elasticity, BASE and CAP vs. ACID, shared-nothing clusters). Four data models with examples: document stores (MongoDB, CouchDB, Riak, Lotus Notes, RavenDB; JSON/XML), column-family (Cassandra, Apache HBase, Hypertable; BigTable-inspired), key-value stores (Project Voldemort, Riak, Redis, Oracle NoSQL, Amazon Dynamo; get/put/multi-get/delete, hash maps), and graph databases (Neo4j, GraphDB, FlockDB from Twitter, OrientDB) for social network analysis. NoSQL disadvantages, plus main-memory databases, stream databases (DSMS), indexing, mirroring, and hot standbys are summarized. The lecture recordings restate these topics with the CoWiz live demo (interactive map and animated timeline comparing countries such as Canada vs. United States).

## Summarized attachments

- **Introduction to Databases and Data Storage Slides** (`CTW-intro-databases-storage_FINAL.pdf`, file): Lecture slides by Sharma Chakravarthy (UT Arlington) introducing databases and data storage for undergraduates. Covers multi-source data analysis challenges using the CoWiz++ COVID-19 dashboard (UT Arlington IT Lab); comparative analysis of Python, R, and Pandas for data analysis; file-based vs. database storage; relational and NoSQL data models; EER and UML modeling; ACID/OLTP/OLAP concepts; commercial RDBMSs (Oracle, IBM DB2, SQL Server, MySQL, PostgreSQL); column-oriented databases (Vertica, SybaseIQ); GIS and ArcGIS software (ArcMap, ArcCatalog, ArcToolbox, extensions), geodatabases; and NoSQL database categories (document stores: MongoDB, CouchDB; key-value: Redis, Dynamo; graph databases: Neo4j for social networks). Includes real-world case study: CoWiz analyzing COVID impact by events (Thanksgiving, Labor Day) across US counties with severity rate classification and regional community detection.
