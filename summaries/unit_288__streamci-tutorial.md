# StreamCI tutorial

Expert-level hands-on tutorial module on StreamCI, a streaming sensor data analysis Cyber Infrastructure. Learning objective: get hands-on exercise on how to ingest data, configure data processing, and access data using StreamCI. Resources are slide decks by Jaewoo Shin (Purdue University, 08/04/2025), supported by NSF awards 1835822, 2230092, and 2513947: `CI4FAIR_StreamCI.pdf` ("Enabling Scalable and Reliable Real Time Data Services for Sensors and Devices in StreamCI") and `CI4FAIR_StreamCI_Tutorial.pdf` ("StreamCI Tutorial" / "StreamCI Hands-on Experience").

**Overview deck (CI4FAIR_StreamCI.pdf):** Motivation — large volumes of sensor/device data from Internet of Things, Smart City, and Precision Agriculture; researchers lack DB/cloud service resources and knowledge. StreamCI is a scalable, flexible sensor data collection and analysis platform enabling researchers to collect, process, store, and access data on the cloud with minimal configuration. Features: data management portal, easy registration, real-time data ingestion, processing pipelines, data query/access API, authentication, and data access control. System design runs on the Anvil Kubernetes Cluster with StreamCI Portal, API Pods, Data Queue, Data processor/Data Pods, Query Queue/Query processor/Query Pods, Management Pod, Auth Pod/Auth Queue, Resource Monitors, Certbot, Mail Queue, and metadata, exposed at api.streamci.org. Data providers register sensor data sources, ingest in real time, preprocess, and store in a cloud database; data consumers access data via API with filters (date/spatial extent, value range) and visualization. Example curl POST requests with JSON auth (target datasource name, username, token) show "insert" and "query" methods against https://api.streamci.org/data and /query (also api.streamci.org:8792).

**Use cases:** (1) Classroom — Purdue's "Ecological Sensors and Data" class pushed environmental sensor data to StreamCI endpoints in real time using the Particle.io webhook mechanism, with Jupyter Notebook for student visualization/analysis. (2) Field — LeafSpec, a low-cost handheld hyperspectral imager for non-destructive leaf scanning and plant physiological measurement, used by researchers for plant phenotyping and by farmers to direct fertilizer/pesticide application; StreamCI provides real-time crop growth monitoring. (3) Manufacturing — pipeline with AWS (Lambda, S3, IoT Core), Purdue AnalytiXIN (AXIN) Data Lake, EMC2, IMI, CERIAS, and a JupyterHub analytics workspace for streaming analytics, monitoring, and prediction; a web platform for real-time facility monitoring, energy usage prediction (indoor temperature prediction with data preprocessing, feature selection, ML training/validation from sensors such as air flow rate, temperature, pump status), and conservation measures for Indiana manufacturers; also anomaly detection in manufacturing processes (U.S. Department of Energy disclaimer). **Future work:** new NSF CSSI Framework grant (July 2025, 5 years, $4M) for an AI-ready streaming data platform — high-level data abstractions, AI-readiness tools, low-code application development, scalable service deployment. Planned use cases: precision audiology (Dr. Heinz), building energy analytics and smart control (Dr. Qu), plant health and smart corn nitrogen fertilization (Dr. Jin), road condition assessment with RGB-D sensors/accelerometers/GPS (Dr. Jahanshahi), Digital Twins for Advanced Manufacturing with spindle load/axis positions (Dr. Jun), wildlife corridors via acoustic data and camera traps (Dr. Bellisario), and environmental sensing and workforce training for water chemistry/air quality (Dr. Hosen).

**Tutorial deck (CI4FAIR_StreamCI_Tutorial.pdf):** StreamCI Management Portal at https://mygeohub.org/groups/gabbs/saci (MyGeoHub registration). Data source registration covers data source name, description, contact information, database type (Default, Timeseries, NoSQL), and write permission (SuperUserWrite, DataProviderWrite, PublicWrite). Data source management: change write permissions, modify super users and data owners, manage schema (default and timeseries), add/remove attributes, set index. Data Viewer: recent data, simple queries, map display. User manual and contacts: admin@streamci.org, shin152@purdue.edu. Hands-on exercise directs learners to the CyberFaCES workshop course page: https://www.cyberfaces.org/learn/course/289-cyberinfrastructure-for-fair-science-workshop/materials.

## Summarized attachments
- **CI4FAIR_StreamCI.pdf** (CI4FAIR_StreamCI.pdf, pdf): Presentation by Jaewoo Shin (Purdue University, NSF awards 1835822, 2230092, 2513947) on StreamCI as a scalable, flexible streaming sensor data analysis cyber infrastructure, covering system design on Anvil Kubernetes Cluster with data ingestion, processing, and query APIs; use cases in classroom (Ecological Sensors and Data course with Particle.io webhooks), field (LeafSpec plant health sensors for crop monitoring), and manufacturing (AWS pipeline with predictive analytics for facility energy usage and anomaly detection).
- **CI4FAIR_StreamCI_Tutorial.pdf** (CI4FAIR_StreamCI_Tutorial.pdf, pdf): Hands-on tutorial guide by Jaewoo Shin covering StreamCI Management Portal access at https://mygeohub.org/groups/gabbs/saci, data source registration process (name, description, contact, database type selection: Default/Timeseries/NoSQL, write permission levels: SuperUserWrite/DataProviderWrite/PublicWrite), data source management functions (permissions, super users, schema management, attribute management, indexing), Data Viewer for querying and map display, and directions to CyberFaCES workshop materials at https://www.cyberfaces.org/learn/course/289-cyberinfrastructure-for-fair-science-workshop/materials.
