# R and Python

Unit covers computational modeling and training resources. References GEMPACK software and RCAC (Rosen Center for Advanced Computing) training offerings.

GEMPACK Installation: Software for computable general equilibrium modeling. Installation requirements: GEMPACK Release 11.0 or later (check via Help...GEMPACK licence in TABmate or ViewHAR); Windows laptop with Administrator access recommended; pre-course installation required (identify and resolve issues before course start); Trial Edition available (6-month temporary license, model size limitations acceptable for training); RunDynam and RunGTAP programs for dynamic simulations and GTAP model solving; QuickInst.pdf and GPInstall.pdf installation documents; MINIMAL free training software available for Practical GE course (Melbourne).

RCAC Training Resources (https://www.rcac.purdue.edu/training): Comprehensive training for RCAC systems, Purdue clusters, and ACCESS Anvil.

Computing and Storage Training: Quick reference cards (Basic Linux commands, RCAC clusters overview).

General Trainings: Containerizing HPC (Singularity/Apptainer), Job Management fundamentals, Quantum Computing (IBM Qiskit), Intel oneAPI series.

Anvil Trainings: Anvil 101 (connecting, environment, job management, data management), Open OnDemand 101, Containerized Bioinformatics, Interactive Computing, VASP introduction.

Purdue-Specific Trainings: Unix 101-202 (basics to advanced), Clusters 101-201 (cluster-specific and job submission), Python Package Installation, Jupyter Kernels and HPC, Research Storage Overview, Fortress Tape Archive, Globus data transfer, Containers 101/Biocontainers 101, Bioinformatics Analysis in HPC, Open OnDemand 101, Workflow Automation Tools (SLURM), AlphaFold Protein Structure Prediction and Visualization (PyMOL).

Data Science & AI Training: Separate page for data science and machine learning; Purdue Indianapolis resources available.

Topics covered: Linux/Unix fundamentals, HPC cluster management, software containerization, Jupyter systems, storage and data management, bioinformatics workflows, quantum computing, protein structure prediction.

## Summarized attachments
- **Installing GEMPACK on your laptop prior to a training course** (www.copsmodels.com/gplapsoft.htm, link): Instructions for installing GEMPACK Release 11.0 or later on Windows laptops for training courses. Covers pre-course installation requirements, Administrator access needs, Trial Edition with 6-month temporary license, QuickInst.pdf and GPInstall.pdf installation documents, model size limitations acceptable for training, optional RunDynam and RunGTAP programs, MINIMAL free training software for Practical GE course, and license upgrading options.
- **RCAC Training** (www.rcac.purdue.edu/training, link): Comprehensive training resources from Rosen Center for Advanced Computing (RCAC) at Purdue University covering Anvil HPC cluster, Purdue clusters, and ACCESS resources. Includes trainings on Linux/Unix fundamentals (Unix 101-202), HPC cluster management (Clusters 101-201), software containerization (Singularity/Apptainer, Biocontainers), Jupyter systems, data management (storage, Globus transfer, Fortress Archive), bioinformatics workflows, quantum computing (IBM Qiskit), protein structure prediction (AlphaFold, PyMOL), and specialized topics like Intel oneAPI and VASP.
