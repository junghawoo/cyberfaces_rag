# Justice in Data: Data Management and Analysis

Comprehensive presentation by Professor Sharma Chakravarthy covering the evolution and fundamentals of data management, analysis, and related technologies. Source file: CTW-DS-intro_FINAL.pdf.

This course traces the history and current state of data handling, from raw data collection through knowledge extraction and decision-making. Foundational concepts include distinguishing data, information, knowledge, and wisdom; the role of metadata and FAIR principles in data interpretation; and the progression from file-based storage to modern database systems.

**Data Management Evolution:** Covers file-based systems, Database Management Systems (DBMS) fundamentals, relational databases, data warehousing, and specialized systems (OLTP, OLAP, data mining systems). Key DBMS concepts include schemas (physical, conceptual, views), data independence, integrity constraints, concurrency control, and recovery mechanisms. Discusses DBMS architecture components: query optimization and execution, buffer management, disk space management, transaction/recovery managers, lock managers. Historical systems referenced include IBM mainframes (System/360, EC1030), minicomputers (PDP-7, PDP-11), and evolution through Network, Hierarchical, and Relational models.

**Advanced Data Systems:** Coverage of Data Warehousing (integrating multiple heterogeneous databases), data marts, OLAP (Online Analytical Processing), Complex Event Processing (CEP/push vs. pull paradigms), and Stream Data Management Systems (DSMS) for real-time sensor data processing. Applications include battlefield monitoring, traffic monitoring, and smart home automation (MavHome Project).

**Mining and Analysis:** Data Mining vs. Statistics vs. Machine Learning distinctions; supervised/unsupervised learning approaches (classification, clustering, association rules, anomaly detection, graph mining, deep learning); data mining cycle (select, preprocess, transform, mine, analyze, rethink); and distinction between correlation and causality. Classic algorithms mentioned: C4.5 (decision trees), K-means clustering, Bayesian theory, regression analysis.

**Big Data and Cloud Computing:** 4V characteristics (Volume, Velocity, Variety, Veracity); technological drivers (inexpensive sensors, mobile devices, storage advances, networking); scientific Big Data examples (CERN Large Hadron Collider ~1000PB/decade, LSST ~100PB by 2025, Pan-STARRS ~4PB/year); enterprise applications across healthcare, retail, manufacturing, geospatial data. Cloud Computing fundamentals: utility computing models, on-demand provisioning, pay-per-use economics, grid computing concepts.

**Data Science:** Convergence of Computer Science, Mathematics, Statistics, Machine Learning, and domain knowledge; moving from traditional DBMS querying toward exploratory analysis; emphasis on visualization, presentation, and process understanding rather than dataset-specific learning. Key distinction: Data Science combines collection, storage, management, querying, search, reporting with exploratory data mining on large, diverse datasets.

**Technical Tools and Languages:** References to C programming (foundational for Unix portability), SQL (DBMS querying), Python, machine learning frameworks, visualization packages. Historical technical context: vacuum tubes, magnetic core memory, magnetic tapes, disk drives (early 5MB storage requiring washing machine-sized cabinets; contrast with modern 32GB microSD cards). Key architectural principle: raising abstraction levels so programmers write fewer lines producing many instructions.

**Applications and Case Studies:** Census data analysis, airline flight analysis, Cowiz++ (COVID visualization using multilayer network analysis), and motivating examples of customer profiling, fraud detection, market basket analysis, risk assessment. Emphasis on domain expertise in interpreting mining results and avoiding spurious correlations.

Core message: Understanding technological provenance and past approaches is essential for appreciating present capabilities and planning future systems. Technology provides solutions but doesn't automatically solve problems; success requires appropriate process design, domain knowledge, and careful validation methodology.
