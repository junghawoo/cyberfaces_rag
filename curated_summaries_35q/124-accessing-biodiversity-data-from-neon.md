## Description
Learners will become familiar with how to download, access, and process biodiversity and other environmental data from the National Environmental Observation Network. Data will be downloaded from cloud servers and stored in CVs and standard database formats.

## Objectives
- Use Python to access USGS NWIS Surface Data Portal
- Using Python to pre-process USGS streamflow data
