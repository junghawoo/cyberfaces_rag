## Description
The objective of this module is to equip students with the knowledge and practical skills needed to utilize geostationary satellite data for the retrospective and near-real-time monitoring of weather hazards. By the end of this module, participants will be able to apply satellite data analysis techniques to detect and analyze various atmospheric phenomena such as storms, fires, and aerosols.

## Objectives
- Understanding the operational characteristics and advantages of geostationary satellites in weather monitoring.
- Learning how to access and manipulate satellite data files using Python tools and libraries.
- Techniques for processing satellite imagery to enhance the visibility of weather features and hazards.
- Applying learned skills to real-world scenarios to identify and analyze specific weather events.
