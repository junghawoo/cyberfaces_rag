# Justice in Data: Preparing undergraduate researchers for success

**Description:** A module-based weeklong (or self-paced) bootcamp designed for undergraduate researchers that focuses on FAIR data principles and machine learning techniques in the Python programming language. The content is wrapped within an engineering research justice context.
