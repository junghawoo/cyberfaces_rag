# Repositories

## Text content

### What is a Repository?
What is a Repository?
A Data Repository is a collection of numeric and/or geospatial data sets for secondary use in research. The purpose of a data repository is to safely store data so it can be accessed easily and used for further research, analysis, and reporting. Public repositories often make storing and accessing data easy for the user, and usually allow for sharing of data between users within the repository.
How Does a Repository Enable FAIR Science?
Large data repositories are often made public, making the data within easy to find and access. Repositories are also often put through extensive quality control to help develop standards for documentation. Quality control also serves to make sure all data is complete and consistent. If data is complete, accurate and consistent, this increases the ability of said data to be used and reused for further research.

### What Are Some Commonly Used Repositories?
PURR - Purdue University has its very own data repository, the Purdue University Research Repository. PURR provides an online workspace for research and collaboration for Purdue students and staff.
https://purr.purdue.edu/
GitHub - GitHub is a repository hosting service that uses Git to allow users to create repositories with ease and to provide users with a variety of data management tools.
https://github.com/
MyGeoHub - The site in which you are accessing this course is also a data repository. It hosts many weather and Earth-based science data sets as well as a variety of tools for research and data management. It also provides work spaces for online courses such as this one.
Data.gov - A repository ran by the US Government, data.gov is home to a wide assortment of open data, covering topics from Agriculture to Ocean data to Public Safety.
https://www.data.gov/
Data.world - This repository is a large, business oriented repository that contains a wide assortment of datasets and which allows for easy collaboration with colleagues on projects. The site also supports built in kits that allow for R and Python code to be written and edited within the repository (Check Modules 3&4 for more info on Python, and Modules 5&6 for info on R).
https://data.world/
Academic Torrents - This repository is similar to PURR, in that it contains mostly scientific research data, but it can be accessed by any researcher as long as they make a log in. The site contains two parts, one in which datasets can be searched for by users and one in which data can be easily shared and distributed.
http://academictorrents.com/
All of these repositories have one thing in common, they all follow FAIR Science practices. Each will be covered in further depth later in this course

What is a Data Repository?
A data repository refers to an enterprise data storage entity (or sometimes entities) into which data has been specifically partitioned for an analytical or reporting purpose.
What do I need to know about data repositories?
The term “data repository” is often used interchangeably with a data warehouse or a data mart. It is a more generalized term, favored when the specific type of data storage entity is not known or is irrelevant to the context. The purpose of a data repository is to keep a certain population of data isolated so that it can be mined for greater insight or business intelligence or to be used for a specific reporting need.
Is a data repository a product?
No. It is a general term to refer to a purpose-built segmentation of data that the business needs for reporting or downstream analytics. However, a data repository can be an instance of a commercial or open source data storage product, such as Oracle or Hadoop.
What are the benefits of a data repository?
The primary benefit is ease of reporting or analysis due to isolation from other data. If you wanted to know which of your remote offices is the most expensive to operate, you could create a data repository for leases, energy costs, facilities, security and utilization, leaving out personnel or business function data.
