1. INTRODUCTION 
Getting enough training and validation sets to optimize a time series model is 
challenging because the time dependencies between observations need to be preserved. 
Traditional resampling method select training and validation data randomly and cannot 
keep the time ordering of dataset. On the contrary, cross-validation procedure can 
preserve the time structure and generate multiple sets for training and validation process 
along time axis.  
The flowchart of optimizing a streamflow forecasting model is shown below. This 
tutorial is the last tutorial in the scenario. The optimization process in this tutorial is 
different from the last tutorial. In this tutorial, you will learn how to optimize Holt-
Winter’s exponential model (HWEM) for streamflow prediction using cross-validation 
technique. Cross-validation procedure resamples streamflow dataset into multiple 
training and validation sets. The errors obtained from each set are averaged into a final 
score for evaluation of HWEM. Optimization process returns a final parameter set of 
HWEM with best score (lowest error) evaluated by cross-validation.

3. GETTING STARTED 
Cross-validation is a resampling method that splits dataset into different folds along the 
time axis. This procedure generates multiple samples of training and validation sets for 
model optimization. The diagram drawn by Hyndman and Athanasopoulos (2018) 
below indicates the procedure of cross-validation. Blue dots represent training set and 
red dot is validation set. There are n days in a single dot. Each step of cross-validation 
generates a sample with one training set and validation set. At first step, the segment of 
training set has the length t (6*n) days and the validation set has the size n days. At next 
step, the length of training set is expanded to t+n (7*n) days, and validation set shifts n 
days along time axis. This procedure continues expanding the training set and moving 
the validation set from the initial training sample toward the last observation. Eventually, 
the last available observation will be hit by validation set. Meanwhile, entire cross-
validation process is done. The averaged error among each step is returned as the final 
score of validation process.

class HoltWinters:
    """
    Holt-Winters model
    # series - initial time series
    # slen - length of a season
    # alpha, beta, gamma - Holt-Winters model coefficients
    # n_preds - predictions 
    """   
    def __init__(self, series, slen, alpha, beta, gamma, n_preds):
        self.series = series
        self.slen = slen
        self.alpha = alpha
        self.beta = beta
        self.gamma = gamma
        self.n_preds = n_preds
        
    def initial_trend(self):
        sum = 0.0
        for i in range(self.slen):
            sum += float(self.series[i+self.slen] - self.series[i]) / self.slen
        return sum / self.slen  
    
    def initial_seasonal_components(self):
        seasonals = {}
        season_averages = []
        n_seasons = int(len(self.series)/self.slen)
        # let's calculate season averages
        for j in range(n_seasons):
            # seasonal mean of streamflow
            season_averages.append(sum(self.series[self.slen*j:self.slen*(j+1)])/float(self.slen))
        # let's calculate initial values
        for i in range(self.slen):
            sum_of_vals_over_avg = 0.0
            for j in range(n_seasons):
                sum_of_vals_over_avg += self.series[self.slen*j+i]-season_averages[j]
            seasonals[i] = sum_of_vals_over_avg/n_seasons
        return seasonals   
    def triple_exponential_smoothing(self):
        self.result = []
        self.Smooth = []
        self.Season = []
        self.Trend = []
        seasonals = self.initial_seasonal_components()        
        for i in range(len(self.series)+self.n_preds):
            if i == 0: # components initialization
                smooth = self.series[0]
                trend = self.initial_trend()
                self.result.append(self.series[0])
                self.Smooth.append(smooth)
                self.Trend.append(trend)
                self.Season.append(seasonals[i%self.slen])                
                continue                
            if i >= len(self.series): # predicting
                m = i - len(self.series) + 1
                val = self.result[i-1]
                last_smooth, smooth = smooth, self.alpha*(val-seasonals[i%self.slen]) + (1-self.alpha)*(smooth+trend)
                trend = self.beta * (smooth-last_smooth) + (1-self.beta)*trend
                seasonals[i%self.slen] = self.gamma*(val-smooth) + (1-self.gamma)*seasonals[i%self.slen]
                self.result.append((smooth + m*trend) + seasonals[i%self.slen])                
                # when predicting we increase uncertainty on each step
            else:
                val = self.series[i-1]
                last_smooth, smooth = smooth, self.alpha*(val-seasonals[i%self.slen]) + (1-self.alpha)*(smooth+trend)
                trend = self.beta * (smooth-last_smooth) + (1-self.beta)*trend
                seasonals[i%self.slen] = self.gamma*(val-smooth) + (1-self.gamma)*seasonals[i%self.slen]
                self.result.append(smooth+trend+seasonals[i%self.slen])                
            self.Smooth.append(smooth)
            self.Trend.append(trend)
            self.Season.append(seasonals[i%self.slen])
