# Why Unix/Linux?

## Text content

### Unix/Linux and FAIR
One reason you might use Linux over other systems is because Linux follows FAIR principles. Linux is findable, accessible, interoperable, and reproducible. Linux is open sourced, which means that its source code is made freely available for viewing, redistribution, and modification. Because Linux is open sourced, it is very findable and accessible. It can be found in numerous places on the internet, and can be freely and easily accessed through downloading. Linux systems are interoperable as well. Linux can run on nearly any computer if it is installed correctly, and can also be run using virtual machines. Data obtained via Linux can easily be incorporated to work with other data. Linux is also reproducible. Again, since Linux is open sourced, its source code is available for modification and redistribution. This makes it very easy for anyone to recreate Linux or something similar to Linux. Data acquired using Linux can also be easily reproduced because the code used is saved. That code can be recreated very easily since there is access to it. You might prefer Linux due to it's FAIR properties. It is findable, accessible, interoperable, and reproducible.

### Advantages of Unix/Linux
Unix like systems and Linux have advantages over other operating systems. One such advantage is that many Linux distributions are free and easy to download. Another advantage is that many Linux systems give more control over the computer and its systems. Linux systems also often are updated regularly making them easier to use and very well maintained. Also, Linux often provides high performance and handles tasks efficiently. Linux, back to its roots, is very good at multitasking, providing access to multiple users, and being portable.
